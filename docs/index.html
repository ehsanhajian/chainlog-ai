chainlog-ai

chainlog-ai answers one question: why did my infrastructure fail?

It reads the logs an operator already has — execution clients, consensus clients, validators, and Kubernetes — and returns a cause that cites those lines. The case stays on the machine.

chainlog-ai explains a failure. ValidatorPulse raises the alert. ChainDiff decides whether an upgrade is safe.

Install

pip install chainlog-ai

Python 3.11 or newer. The README is the source of truth, including the example logs.
